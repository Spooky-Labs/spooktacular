Built from source, for now.

macOS virtualization for teams on Apple silicon. Free, open source, MIT licensed — zero cost, forever. Spooktacular is pre-1.0 and there are no signed binary releases yet, so today the install is a clone and one build script.

Get the source on GitHub Get started
$ git clone https://github.com/Spooky-Labs/spooktacular.git

What you need

Spooktacular is Apple-native, so the list is short: an Apple silicon Mac and current Apple tooling.

Host

macOS 27

Required for macOS guests — the shared base image is built with DiskImageKit on Apple's Virtualization framework.

Hardware

Apple silicon

M1, M2, M3, M4, or later. Intel Macs are not supported.

Toolchain

Xcode 27

Spooktacular builds with Xcode 27. ./build-app.sh drives the build for you.

Disk

35 GB free

For the app plus one macOS VM. Clones share blocks with the base, so each one starts near zero.

Build in three steps

Clone, run the build script, and drag the app into Applications. That is the whole install.

build from source
$ git clone https://github.com/Spooky-Labs/spooktacular.git
$ cd spooktacular
$ ./build-app.sh release
# then drag the built Spooktacular.app into /Applications

Signed, notarized builds will appear on the GitHub Releases page when they are published. Until then, building from source is the supported install.

Planned install methods

Both Homebrew paths are planned but not published yet. Build from source in the meantime.

Planned

Homebrew cask

Planned

Install just the spook CLI for headless workflows and CI/CD with brew install spooktacular. Not published yet.
